فایل‌های فونت «B Yekan» را اینجا بگذارید (نام فایل باید شامل Yekan باشد، مثلاً BYekan.ttf و BYekanBold.ttf).
پسوندهای پشتیبانی‌شده: ttf / woff / woff2 / otf
اگر فونت پیدا نشود، به‌طور خودکار از Vazirmatn استفاده می‌شود.
بعد از گذاشتن فایل‌ها لازم نیست برنامه را دوباره نصب کنید؛ فقط برنامه را یک بار ببندید و دوباره اجرا کنید.
