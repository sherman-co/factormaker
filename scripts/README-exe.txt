پنل پیش‌فاکتور فروش - نسخه‌ی اجرایی ویندوز
============================================

اجرا:
1) فایل FactorMaker.exe را دوبار کلیک کنید (اگر ویندوز هشدار SmartScreen داد: More info ← Run anyway).
2) پنجره‌ی سیاه باز می‌شود و مرورگر خودش آدرس http://127.0.0.1:3000 را باز می‌کند.
   (اگر باز نشد، همین آدرس را دستی در Chrome یا Edge بزنید.)
3) اولین ورود: نام کاربری admin و رمز admin1234 (حتماً در «تنظیمات» عوض کنید).

توقف: پنجره‌ی سیاه را ببندید (یا Ctrl+C).

نکته‌ها:
- ساخت PDF به مرورگر Google Chrome یا Microsoft Edge روی همین کامپیوتر نیاز دارد (Edge در ویندوز ۱۰/۱۱ هست).
- همه‌ی اطلاعات در پوشه‌ی data کنار برنامه ساخته می‌شود؛ برای بکاپ همان پوشه را کپی کنید.
- برای ارتقا: پوشه‌ی data را نگه دارید و بقیه‌ی فایل‌ها را با نسخه‌ی جدید جایگزین کنید.
- فونت B Yekan را داخل پوشه‌ی fonts بگذارید (نام فایل باید شامل Yekan باشد)؛ بعد برنامه را دوباره اجرا کنید.
- اگر پورت ۳۰۰۰ اشغال بود، در cmd بنویسید:  set PORT=3001 && FactorMaker.exe
